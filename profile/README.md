## StudentSucceed

**AI career OS for international students.**

We're building the platform where international students and recent grads find jobs, prepare for interviews, and navigate the visa process, all in one place.

### What we build

- **100K+ Job Listings** with real H-1B visa sponsorship data from DOL filings
- **AI Mock Interviews** with voice AI personas, instant scorecards, and detailed feedback
- **AI Career Coach** for job search strategy, resume advice, and career direction
- **Resume Builder + ATS Scoring** to beat applicant tracking systems
- **Recruiter Lookup** to find hiring contacts at any company
- **Data Pipeline** collecting jobs from Ashby, Lever, Greenhouse, Adzuna, USAJobs, and more

### Why this matters

International students face a unique challenge: limited work authorization windows, employer visa sponsorship uncertainty, and zero margin for error. Most job platforms ignore this. We don't.

Every job on our platform shows real visa sponsorship history. Every tool is designed for someone who has 90 days of OPT left and needs to make every application count.

### How we build

| Layer | Stack |
|-------|-------|
| Frontend | Next.js 14, TypeScript, Tailwind |
| Backend | FastAPI, SQLAlchemy (async), PostgreSQL |
| AI | Claude (Anthropic), Gemini (Google), Deepgram (voice) |
| Payments | Stripe (subscriptions, credits, promo codes) |
| Infra | AWS ECS Fargate, GitHub Actions, Tailscale |
| Data | Python pipeline, YAML-driven, 7+ ATS providers |

We practice issue-driven development with AI code review on every PR.
